## The Brutally Honest Advisor
*Candid, no-flattery feedback on an idea or decision.*

```
You are a brutally honest advisor with 20 years of experience. I value the truth over my feelings.

Review what I share and tell me:
1. The strongest part of this — be specific about why.
2. The weakest part — the thing most likely to make this fail.
3. The blind spot I'm probably not seeing.
4. What you would do if this were yours.

Don't soften it. If it's a bad idea, say so and explain.

{YOUR IDEA}
```

## Turn Chaos Into a Plan
*Turns a messy brain-dump into a clear, prioritized plan.*

```
Here is an unfiltered brain-dump of everything on my mind. Help me make sense of it.

1. Group these into clear categories.
2. Flag the 3 things that actually matter most right now (and why).
3. Give me a simple plan for today — 3 concrete actions, in order.
4. Tell me what I can safely ignore or drop.

{BRAIN DUMP}
```

## Explain This Code Like I'm New
*Plain-English, line-by-line code explanation.*

```
Explain the following code to me like I'm new to programming.

1. One sentence: what does this code do overall?
2. Walk through it in plain English, section by section.
3. Point out anything risky, surprising, or that I should be careful with.
4. Suggest one small improvement and why.

Avoid jargon. When you must use a technical term, define it.

{CODE}
```

## Teach Me Anything (Feynman Method)
*Learns you any topic — simple first, then deeper — and checks you got it.*

```
Teach me about {TOPIC} using the Feynman technique.

1. Explain it to me like I'm 12 — simple words, a real-world analogy.
2. Then go one level deeper for an adult who's curious.
3. Give me the 3 things most people get wrong about it.
4. End by asking me one question to check I understood — and wait for my answer.
```

## Steelman Both Sides
*Argues the strongest case for each option of a hard decision.*

```
I have a decision to make. Help me think clearly.

1. Make the strongest honest case FOR each option (steelman, not strawman).
2. Make the strongest case AGAINST each.
3. Name the one factor that should decide this.
4. Give me your recommendation and your confidence level.

Decision: {DECISION}
```

## The Pre-Mortem
*Imagines your plan already failed, then finds the risks before they happen.*

```
Run a pre-mortem on my plan.

Plan: {PLAN}

Imagine it's 6 months later and this failed badly. Tell me:
1. The 5 most likely reasons it failed.
2. The earliest warning sign of each.
3. One thing I can do now to prevent or soften each.
Be specific and a little pessimistic — that's the point.
```
